## 🏗️ Mimari

```
AppProvider (Context API)
│
├── users / workouts / messages / gallery      → localStorage senkronizasyonu
├── currentUser / rol & hızlı hesap geçişi
├── activePage                                 → 7 sayfa arası yönlendirme
└── modallar                                   → giriş, antrenman, eğitmen, mesaj, deploy
        │
        ├── pages/         Home · About · Trainers · Workouts · Gallery · Contact · Dashboard
        ├── components/    Navbar · Footer · modallar
        └── data/          seedData (6 kullanıcı · 6 antrenman · 5 galeri · 2 mesaj)
```

## 🚀 Çalıştırma

```bash
npm install
npm run dev
```

Ardından `http://localhost:3000` adresini aç.

```bash
npm run build     # üretim derlemesi
npm run preview   # derlemeyi önizle
```

## 💾 Veri & kalıcılık

| Anahtar | İçerik |
|---|---|
| `misfit_users` | Kullanıcılar ve roller |
| `misfit_workouts` | Antrenman seansları ve kayıtlar |
| `misfit_messages` | İletişim mesajları |
| `misfit_gallery` | Galeri görselleri |
| `misfit_current_user_id` | Aktif oturum |

- İlk açılışta örnek veriler yüklenir.
- Footer'daki **“Verileri Sıfırla”** düğmesiyle başlangıç verilerine dönülebilir.
- Tüm değişiklikler anında `localStorage`'a yazılır.
