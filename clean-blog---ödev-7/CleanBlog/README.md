# Clean Blog Projesi Başlangıç (Ödev 7)

Bu proje, Node.js ve Express.js öğrenme sürecinde PCAT projesinin ardından pratik yapmak amacıyla hazırlanmış **Clean Blog** projesinin başlangıç adımıdır.

## 📌 Ödev 7 Kapsamında Yapılanlar:
1. ✅ **CleanBlog** proje klasörü oluşturuldu.
2. ✅ **package.json** dosyası oluşturuldu.
3. ✅ **Prettier** ayarları (`.prettierrc`) eklendi.
4. ✅ **express** ve **nodemon** paketleri kuruldu.
5. ✅ `git init` ile yerel git reposu oluşturuldu.
6. ✅ GET isteği ile `const blog = { id: 1, title: "Blog title", description: "Blog description" }` nesnesi döndürüldü.
7. ✅ `.gitignore` dosyası oluşturuldu ve ilk git commit **ENES Öztürk** imzasıyla kaydedildi.

## 🚀 Çalıştırma:
```bash
npm install
npm start
```
Tarayıcınızdan `http://localhost:3000` adresine gittiğinizde blog nesnesi JSON olarak döndürülür:
```json
{
  "id": 1,
  "title": "Blog title",
  "description": "Blog description"
}
```
